The local-first, self-evolving AI agent runtime in Rust.

EvoClaw runs the agent loop on your laptop. It learns from every task, scrubs secrets before they reach the model API, and cuts long-session token cost by roughly 70 percent. ACP + MCP standard interop. MIT licensed.

Why a new runtime?

A modern coding agent reads your code, runs shell commands, hits APIs, writes files. That's a long capability list to extend toward something you don't control. EvoClaw fills the local-first cell of that matrix.

Your code stays local.

Only the model API call leaves the machine. Hosted-SaaS agents log every prompt; EvoClaw scrubs the prompt at the runtime boundary and persists everything else under ~/.evoclaw/.

Your secrets never reach the model.

The redactor runs at six injection points inside the runtime. Vault-registered values become ${SECRET:NAME}; unregistered credential shapes become [REDACTED:kind:fp]. Both layers are idempotent.

Your costs stay sane.

Five stacked tricks — schema fingerprint, ephemeral cache, summary protocol, head+tail truncation, periodic compression — drop a long task to roughly one third of the naive spend. Each trick is unit-tested.

What's in the box

Self-evolving skill tree

Every task ends in a reflection round, distilled into a YAML Skill on disk. Five-state EWMA lifecycle: Draft → Candidate → Active → Degraded → Deprecated. Active skills feed the next planner round. evoclaw skill tree.

Layered memory (L0–L5)

L0 scratch, L1 user prefs, L2 env facts (90-day age-out), L3 task records, L4 model reflections, L5 cold archive. JSONL + grep on purpose. Vector retrieval costs prompt tokens; substring match against typed layers doesn't.

Append-only JSONL replay

One log per task, one JSON per record (Task / Turn / End). evoclaw replay rehydrates any session. doctor closure audits that every log is fully closed.

Three-tier budget engine

Per-task hard stop, per-day soft warn + hard cap (4×), per-month hard cap. doctor-of tokens shows 7-day / 30-day spend and cache-hit rate.

P0–P8 permission ladder

Ordered ladder enforced inside evo-policy::Permission. Default ceiling P1 (workspace write). Channel senders are hard-capped at P4 regardless of config.

Two binaries, one CLI

evoclaw (long form) and evo (3-letter alias) call the same library. Run with no subcommand to enter the REPL — just like the upstream coding CLIs.

Secret-redaction barrier

Two complementary defences. No raw key, password or OAuth token ever leaves your machine via the model API.

Standard protocol interop

ACP — delegate the loop

Set provider = "acp:claude" (or codex, cursor, copilot) in ~/.evoclaw/config.toml. EvoClaw spawns the upstream CLI as a subprocess and routes prompts through ACP (JSON-RPC over stdio). Auth stays inside the upstream CLI.

MCP — bring your own tools

Run any standard Anthropic Model Context Protocol server — filesystem, GitHub, fetch, time, Brave Search, Postgres, Slack, or your own. Tools surface as mcp__server__tool in the registry. Auth env vars are captured at mcp add time and never reach the model.

Quickstart

Build, type evoclaw, follow the wizard. No package registry. No telemetry. No "create an account first."

git clone https://github.com/DevEloLin/evoclaw && cd evoclaw
cargo build --workspace --release
./target/release/evoclaw                 # interactive setup wizard runs on first launch

# Register a secret — value never leaves the machine
evoclaw secret add github_pat ghp_yourActualValueHere

# Run a task
evoclaw run "diagnose why my SSH hangs intermittently"

# Replay it
evoclaw replay

Frequently asked

What is EvoClaw, in one sentence?

A local-first agent runtime in Rust that learns from every task, proves its work in append-only JSONL logs, and never lets a secret you typed reach the model API.

Does it work offline?

Yes. Point model.base_url at http://localhost:11434/v1 for Ollama, or any local vLLM / llama.cpp server. Skip the API key step. The redactor and skill tree still work.

Will my skills survive a re-clone of the repo?

Yes. State lives in ~/.evoclaw/, not in the repo. Wipe and rebuild EvoClaw all you want; your skills, memory, and vault stay put.

Can I share a session log with a coworker?

Yes. Every text field is scrubbed before it's written, so the JSONL is safe to share without manual review.

What stops the model from echoing my secret right back into the log?

The redactor scrubs both on the way to the model and on the way back from it. If the model surprises us by echoing a registered value, the assistant text gets scrubbed again before it lands in the JSONL.

Why no vector database?

Vector retrieval costs prompt tokens at retrieval time. Substring matching against typed memory layers (L1 prefs, L2 env facts, L3 task records) hits the same recall on local-machine workloads at a fraction of the prompt cost. If you want vectors, plug in an MCP server with a vector backend.

Why Rust?

Single static binary, no runtime, no GC pauses; the type system catches a class of bugs that matter in a long-running agent runtime. We get all of that without the C++ tax.

How do I switch model providers?

Run evoclaw login and pick a different one, or edit ~/.evoclaw/config.toml directly. EvoClaw supports DeepSeek, Kimi, Qwen, OpenAI, OpenRouter, Anthropic, GitHub Copilot, Ollama, and any OpenAI-compatible endpoint.
