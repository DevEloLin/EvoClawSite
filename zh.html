本地优先、自主进化的 Rust AI Agent Runtime

EvoClaw 把 agent 循环跑在你自己的笔记本上。每次任务都在学习、密钥在 runtime 边界就被脱敏不会进入模型 API、长会话 token 成本降到约 1/3。ACP + MCP 标准协议互通。MIT 开源。

为什么再做一个 Agent Runtime？

现代 coding agent 能读你的代码、跑 shell、调外部 API、写文件 —— 这是相当长的一份能力清单要交给一个不归你管的东西。EvoClaw 填的是矩阵里"本地优先"那一格。

代码留在本机

唯一出本机的网络调用是你自己选的模型 API。其他东西全部落到 ~/.evoclaw/ 下。托管 SaaS agent 把 prompt 进它们的日志，EvoClaw 在 runtime 边界处把 prompt 先 scrub 一遍。

密钥不会进模型

Redactor 在 ConversationRuntime 的 6 个注入点都会跑。Vault 已注册的值替换为 ${SECRET:NAME}，未注册但形状像凭据的串替换为 [REDACTED:kind:fp]。两层都是幂等的。

花费可控

5 招叠加 — schema 指纹、ephemeral cache、summary 协议、头尾截断、周期压缩 — 让长任务实测花费降到约 1/3。每招都有单元测试压住。

开箱即得

自主进化的 Skill Tree

每次任务结束都跑一次反思回合，蒸馏出一份 YAML Skill 写到磁盘。五态机 EWMA 老化：Draft → Candidate → Active → Degraded → Deprecated。Active 自动喂给下次 planner。evoclaw skill tree。

分层记忆 L0 至 L5

L0 scratch、L1 用户偏好、L2 环境事实（90 天 age out）、L3 任务记录、L4 模型反思、L5 冷存。**故意做的** JSONL + grep —— 向量在检索时要花 prompt token；针对类型化记忆层的子串匹配不会。

Append-only JSONL 回放

一任务一份日志，一记录一行 JSON（Task / Turn / End）。evoclaw replay 重建任意会话；doctor closure 审计每份日志是否完整闭环。

三级预算引擎

per-task hard stop、per-day soft warn + hard cap（4×）、per-month hard cap。doctor-of tokens 看 7 天 / 30 天花费与缓存命中率。

P0 至 P8 权限阶梯

由 evo-policy::Permission 全序约束。默认上限 P1（workspace 写）。渠道发送方无视 config 硬封顶 P4。

双 binary，单 CLI

evoclaw（长格式）与 evo（3 字母短别名）共享同一份 lib。不带子命令直接进 REPL —— 跟主流 coding CLI 一致的体验。

密钥隔离屏障

两层互补防线。用户输入的任意 key / 密码 / OAuth token 永不通过模型 API 离开本机。

标准协议互通

ACP — 把循环交出去

在 ~/.evoclaw/config.toml 设 provider = "acp:claude"（或 codex / cursor / copilot）。EvoClaw 把上游 CLI spawn 成子进程，通过 ACP（JSON-RPC over stdio）转发 prompt。认证留在上游 CLI 自己手里。

MCP — 自带工具进来

跑任意标准 Anthropic Model Context Protocol 服务器 —— filesystem / GitHub / fetch / time / Brave / Postgres / Slack 或自写。工具在 ToolRegistry 中以 mcp__server__tool 命名。鉴权 env 在 mcp add 时落盘，模型完全看不见。

快速上手

编译 → 敲 evoclaw → 跟向导走。无需包管理器。零遥测。无需注册账号。

git clone https://github.com/DevEloLin/evoclaw && cd evoclaw
cargo build --workspace --release
./target/release/evoclaw                 # 首次启动会跑交互式向导

# 注册密钥 —— 原值永不出本机
evoclaw secret add github_pat ghp_yourActualValueHere

# 跑任务
evoclaw run "排查为什么我连生产机的 SSH 偶尔卡住"

# 复盘
evoclaw replay

常见问题

EvoClaw 是什么，一句话？

用 Rust 写的本地优先 agent runtime，每次任务都在学，工作过程在 append-only 日志里可以证明，你输入的密钥永远不会到模型。

能离线用吗？

能。model.base_url 指 http://localhost:11434/v1（Ollama）或任意本地 vLLM / llama.cpp 服务，跳过 API key 步骤。redactor 与 skill tree 仍然工作。

重新 clone 仓库后我的 skill 还在吗？

在。状态在 ~/.evoclaw/，不在仓库里。EvoClaw 整体 wipe 重建多少次都行，skill / memory / vault 都不会丢。

能把 session 日志分享给同事吗？

能。每个文本字段在写入前已经 scrub 过，JSONL 默认安全可分享。

模型把我的密钥从历史里"念"回到日志里怎么办？

去模型路上 scrub 一次，回程 scrub 一次。即使模型出于某种原因把已注册的值回显出来，那段 assistant text 在写 JSONL 之前还会被 scrub 一次。

为什么不用向量数据库？

向量检索的成本是"对 query 做 embedding，把 top-k 块送回 context"。能跑，但既不便宜也不易审计。在本地工作负载下，针对类型化记忆层做纯文本 grep，召回率相当但 prompt 成本只有零头。如果你的工作负载不适合，挂一个带向量后端的 MCP server 即可。

为什么用 Rust？

单一静态 binary，无运行时，无 GC 暂停；类型系统能在编译期挡掉一类对长程运行的 agent runtime 真正有杀伤力的 bug。这些都拿到，还不必交 C++ 税。

怎么切换模型 provider？

跑 evoclaw login 重选，或者直接编辑 ~/.evoclaw/config.toml。EvoClaw 支持 DeepSeek、Kimi、Qwen、OpenAI、OpenRouter、Anthropic、GitHub Copilot、Ollama 以及任意 OpenAI 兼容端点。
